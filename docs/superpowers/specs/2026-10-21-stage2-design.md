# 第二阶段：瓜瓜物语上线

沿用 aacb187 工程，用户已授权自主设计、提交和免费发布。旧 xiaomin 仓库、项目及域名只读。

`/` 改为暖黄色水果开始页，游戏名称《瓜瓜物语》；开始跳到 `/game` 自动创建零分会话并加载原 Cocos。`/game` 不渲染站点导航、页脚、介绍或侧栏，使用 100dvh 全屏，桌面限制画布容器比例但手机全宽全高。排行榜图标打开原位覆盖层并暂停，关闭后恢复此前暂停状态。隐私入口在首页底角，作品站迁至 `/lab`。

匿名浏览器 Cookie 延用，数据库给 players 增加递增 number，公开显示 IP-001 等编号；IP 仅为编号前缀，不参与身份合并。公共榜不再返回昵称或 UUID。先建立签名浏览器 Cookie，再创建游戏，保持幂等、实时得分、失败重试和退出补传。

新增可启停、可删除的玩家/网络排除规则。IP 在服务器校验并规范化后 HMAC，数据库不存原文。classified_sessions 视图在每次查询时计算规则影响；规则可选追溯既有记录，关闭/删除可恢复由该规则排除的成绩，不改变原始分数。旧版本 is_test 手动标记保留，单独支持当前浏览器恢复。规则永远不授予管理员权限。后台默认正式记录，支持全部/正式/测试，设备、当前网络、手动 IP 和记录操作统一调用同一安全服务端规则接口。

迁移增量执行，不清空旧数据。测试真实 PostgreSQL SQL、匿名编号、规则撤销/重叠/追溯/非越权和得分不回退。浏览器分别检查 360×800、393×873、430×932 画布边界、滚动条及覆盖榜；生产待真实 Vercel/Neon 登录和用户密码，不能把本地验证当生产成功。
