## 本地完整链路

另用**临时内存 PostgreSQL 引擎**运行同一生产 API handlers，代理生产构建页面；没有给生产代码添加数据库替身或公开测试 API。该工具只存在开发工作目录，不在交付应用或 GitHub 源码中。

浏览器输入昵称「本地真实游戏验收」，联网开局；数据库立即记录 0 分。实际操作原版游戏触发合成后，外层显示真实 1 分，「服务端已确认」为 1；未结束会话进入总榜，昵称、1 分、排名 #1 和北京时间正确显示。没有通过代码注入分数，也没有展示虚假榜单。

这些临时验收数据在本地测试服务关闭时销毁，不是 Neon 生产数据，也不会随部署发布。
