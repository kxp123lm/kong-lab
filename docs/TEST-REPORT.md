## 边界

分数来自真实原游戏事件，但浏览器单机客户端无法提供绝对可信的反作弊证明。网络突然中断或关闭页面只保证最后一次服务端确认的分数。共享 IP 网络规则可能影响多人，建议优先使用设备规则。自动化手机尺寸验证不能替代用户真实手机硬件、Safari 工具栏和刘海安全区的最终检查。
